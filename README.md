# KAGURA ASCENT ― 神楽

Godot 4.7 製の縦スクロールシューティング。魔法少女が参道を登り、八百万の神々から
恩恵（Boon）を授かって強くなる。成長システムは『Hades』の恩恵システムを
日本神話に置き換えたもので、**最初に選んだ神が主神、のちに恩恵を受けた 2 柱が副神**になる。

- 自機は `image/walk.gif` の後半（自然な歩行部分）から切り出した後ろ姿のスプライト
- タイトルは `image/title.png`
- 敵・弾・エフェクト・UI はすべて `_draw()` によるプロシージャル描画、効果音は起動時に波形合成
- 将来のブラウザ配信を前提に、レンダラーは Compatibility、日本語フォントはプロジェクトに同梱

## 遊び方

```sh
godot --path .          # 直接起動
godot -e --path .       # エディタで開く
```

| 操作 | キー |
| --- | --- |
| 移動 | WASD / 矢印キー |
| 攻撃 | 自動 |
| 特技（御札） | 自動（周期的に放つ） |
| 詠唱 | Z / J（強い一撃。2 発まで貯まる） |
| 疾走 | Space（短時間無敵。足元の輪が満ちると再使用可） |
| 神招き | X / K（ゲージ 1/4 以上で発動。満タンなら大神招き） |
| 低速移動（当たり判定表示） | Shift |
| 選択 | 1〜9 またはクリック |
| 神籤の引き直し | R（恩恵選択ごとに 1 回） |
| 小休止 / ミュート | P / M |
| タイトルへ戻る / 終了 | Esc |

### スマホ（タッチ操作）

- 画面のどこでも指をなぞると、その移動量ぶん自機が動く（指で自機が隠れない相対移動）。
  移動速度の補正（道開きの加護、烏、月の重みなど）は指への追従率として効く。速い自機は同じ指の動きでより遠くへ動き、遅い自機は粘る
- 短くなぞってすぐ離す（スワイプ）と、その方向へ**疾走**。指を離さずに速く動かしても出ない（ボタンはない）
- 画面下の丸ボタン：左が**神招き**、右が**詠唱**。右上の「休」で小休止
- 選択画面・タイトル・ゲームオーバーはタップで選ぶ
- 縦長の端末では横幅を基準に画面いっぱいまでプレイ領域が広がる（黒帯なし）

## ゲームの流れ

1. ウェーブごとに穢れ（敵）が降ってくる。全滅させるとクリア。**8 波で 1 ステージ、全 3 ステージ**
   （参道 → 拝殿 → 奥宮）。各ステージの最後の波に大妖（ボス）が出て、奥宮の最後はラスボス「八岐大蛇」。
   倒すと踏破（クリア）。ボス戦中も雑魚の増援が周期的に出る。敵の HP と物量は後半ほど急に増える。
2. 敵を倒すと勾玉（経験値）が落ちる。位（レベル）が上がった瞬間に時間が止まり、神との邂逅になる。
3. **位 2（最初の邂逅）では 3 柱から主神を選ぶ。** 選ぶ前に契約の確認画面が出て、神の絵と詳しい説明、
   契約の代償（最大 HP -10% などの軽い実効と、ユーモアのある二つ目）を見せる。契約すると神器が付く。
   **神を迎える瞬間はそれ自体が報酬で、続けて別の選択は出ない。**
4. **位 4 と位 7 では残る神から 3 柱が現れ、副神を迎える**（神器が半分の威力で加わる。同じ契約の確認あり）。
   それ以外の位上がりでは迎えている神が現れ、能力を 3 枚提示する（新たな神のカードは混ざらない）。
   **神ごとの能力は 9 種（凡 4・稀 3・秀 2）で、1 柱につき 3 つまで選べる。** 提示は空き枠のぶんが新しい能力、
   残りは選んだ能力の強化（例：1 つ選んでいれば 新規 2 枚＋強化 1 枚）。伝説・双神・禍神の取引は 1 枚だけ混ざる。
   HUD の神々の欄と恩恵画面の下段に「位 N で迎える」と次の邂逅が予告される。
5. 神器は敵に当てるほど**神徳**が溜まり、**神格**が自動で上がる（威力 +12%/段、節目で弾数や大きさが増える）。
6. 3 波ごととボス撃破時に**神酒**が降る。拾うと神を 1 柱選んで神格を 1 段上げられる。
7. 詠唱（Z）と神招き（X）は主神の技。神招きはダメージを与える・受けるとゲージが溜まり、1/4 で発動、満タンで大神招き。

## 恩恵システム（Hades との対応）

| Hades | 本作 |
| --- | --- |
| 神ごとの恩恵で武器が変わる | 神を迎えると**神器**（自動発射の武器）が付く。主神 100% / 副神 50% |
| 神ごとの状態異常（Jolted, Doom, Weak…） | 神ごとの**神威**（帯電・宿命・弱体…）。敵にオーラ・泡・結晶などの専用演出 |
| Common / Rare / Epic / Heroic | 凡 / 稀 / 秀 / 英（倍率 ×1.0 / 1.35 / 1.8 / 2.3） |
| Legendary（同神の恩恵 2 つが前提） | 伝説（**主神のみ**、その神の強化 2 つ以上） |
| Duo Boon（2 神の恩恵が前提） | 双神（2 柱を迎え、それぞれの強化を持つ） |
| Pom of Power（レベルアップ、逓減） | 恩恵は重ねて取れる（逓減）。神酒は神格を 1 段上げる |
| God Gauge / Greater Call | 神招きゲージ（1/4 で発動、満タンで大神招き） |
| Fated Persuasion（再抽選） | 神籤の引き直し |
| ― | 神格：神器を当てるほど神徳が溜まり自動で強くなる（本作独自） |

各神に 9 種の能力（凡 4・稀 3・秀 2。3 つまで選べ、重ねて強化できる）と伝説（主神のみ、能力 2 つ以上で出現）がある。
格（凡・稀・秀）は能力そのものの設計上の強さで、数値の倍率ではなく、稀・秀ほど出にくい（位が上がると出やすくなる）。
数値は `base × レアリティ倍率（凡 1.0 / 稀 1.35 / 秀 1.8 / 英 2.3）+ 重ねた回数の補正` で決まり、
データはすべて `scripts/kami.gd` にある。

### 設計メモ

- **命中は必ず `Combat.hit()` を通す。** 照覧・弱体などの倍率、会心、神威の付与、双神・伝説の
  派生効果を一箇所で処理する。弾は「どのスロットの弾か（slot）」と「どの神の弾か（kami）」だけを持つ。
- **恩恵の値は保存しない。** `Player.val(id)` が `Kami.value(base, rar, lv)` を毎回計算する。
- **神器の威力は `Player.kami_power(kami)`。** 主神 1.0 / 副神 0.5 × 神格倍率。神徳は `Combat.hit` が
  kami 付きのダメージから自動で加算する。
- **シグナル処理中にノードを生やさない。** `area_entered` の最中に `Area2D` を `add_child` すると
  物理サーバのフラッシュ中エラーになる。生成は `Game.spawn_deferred()` か `call_deferred` を通す。
- **ヒットストップは `Game.hitstop(dur, scale)`。** 会心・宿命・砕け・ボスのフェーズ変化・神招きで
  時間の流れを一瞬止め、手応えを出す。UI と Game は `PROCESS_MODE_ALWAYS`。
- **ポーズは `get_tree().paused`。** 選択画面はすべてポーズ中に描かれる。

## ブラウザ版

公開先（GitHub Pages）: <https://hiroakit-roko.github.io/kagura/>

`main` に push すると `.github/workflows/deploy-pages.yml` が Godot 4.7.1 のコンテナで Web 版を
書き出し、そのまま GitHub Pages にデプロイする。手元で `build/` をコミットする必要はない。

Godot の Web 書き出しは Compatibility レンダラーのみ対応なので、デスクトップ版も同じ
レンダラーで動かして見た目を揃えている。Glow は Compatibility では簡易実装になるため、
`glow_hdr_threshold` を 1.0 未満（0.82）にしている。OS フォントは Web で使えないので、
日本語フォントを同梱している。

```sh
# エクスポートテンプレート（4.7.1）を入れたうえで
godot --headless --path . --export-release Web build/web/index.html
cd build/web && python3 -m http.server 8080   # http://localhost:8080/
```

- `variant/thread_support=false` にしているので COOP/COEP ヘッダなしで動く（itch.io 等でそのまま可）。
- 効果音は実行時生成の `AudioStreamWAV` なので、Web の既定（Sample 再生）で問題ない。
  BGM（mp3、約 7 分）はメモリ展開を避けるためストリーム再生を指定している。
- ブラウザの自動再生制限により、最初のクリック／キー入力までは音が出ない。
- 見出しフォントは使用文字だけに絞っている。神や恩恵の文言を追加したら
  `python3 tools/subset_fonts.py <ShipporiMinchoB1-Bold.ttf>` を再実行する。

## 開発用ツール

自動プレイしながら要所のスクリーンショットを保存する：

```sh
godot --path . -- --capture              # 120 秒プレイして撮影（主神選択・恩恵・神酒・ボスなど）
godot --path . -- --capture --deathtest  # ゲームオーバー→リスタート→ポーズを確認
```

出力先は `~/Library/Application Support/Godot/app_userdata/KAGURA ASCENT/shots/`。

## 記録の保存（名前・スコア）

- 結果画面で上位 10 件に入ると「第 N 位に刻まれた」と出て、名前（10 文字まで）を入力できる。題目画面でも名前を変えられる。
- 保存先は `user://save.cfg`。Web 版ではブラウザの IndexedDB に置かれるので、GitHub Pages のような静的配信でも
  同じ端末・同じブラウザなら次回も残る。**他の端末や他のプレイヤーとは共有されない**（サーバーがないため）。
- 全員共通のランキングにするには外部の保存先（Supabase / Firebase / Cloudflare Workers KV などの無料枠）が 1 つ必要。
  ゲーム側は HTTPRequest で送受信するだけで済む。
